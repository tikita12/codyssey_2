## 🌿 브랜치란?
>기존의 코드에 새로운 코드를 추가 및 수정할 때 원래 코드에 영향을 주지 않는 브랜치를 만들어서 작업하는 것
>안전성과 협업에서 중요
>Git 브랜치(Branch) 주요 명령어

| 명령어 | 설명 |
| :--- | :--- |
| `git branch` | 현재 만들어진 브랜치 목록을 확인합니다. |
| `git branch [이름]` | 새로운 브랜치를 생성합니다. |
| `git checkout [이름]` | 해당 브랜치로 이동합니다. (최신 버전은 `git switch` 권장) |
| `git merge [이름]` | 현재 브랜치에 지정한 브랜치의 내용을 합칩니다. |
| `git branch -d [이름]` | 작업이 끝난 브랜치를 삭제합니다. |

## 🌿 Git / 브랜치 작업 내역
#### 1. 사용한 Git 명령어 상황
* `git init`: 프로젝트 시작 시, 로컬 저장소를 초기화하고 버전 관리를 시작할 때 사용했습니다.
* `git clone`: 원격 저장소(GitHub)에 있는 코드를 내 컴퓨터로 처음 가져올 때 사용했습니다.
* `git add`: 새로운 기능(추가, 조회, 삭제, 검색 등)을 구현한 후, 변경된 파일을 스테이징 영역에 올릴 때 사용했습니다.
* `git commit`: "상세보기 기능 추가", "순위 기능 추가" 등 각 작업 단위마다 의미 있는 메시지를 남겨 버전을 기록했습니다.
* `git push`: 로컬에서 작업하고 커밋한 내용을 GitHub 원격 저장소(`origin/main`)에 업로드했습니다.
* `git pull`: 원격 저장소의 최신 변경 사항을 로컬로 가져와 동기화했습니다.
* `git checkout`: 기능을 분리해서 작업하기 위해 `main` 브랜치에서 `fix-view`나 `fix-favorite` 브랜치로 이동할 때 사용했습니다.
* `git merge`: 별도의 브랜치에서 작업이 완료된 기능을 메인 줄기인 `main` 브랜치에 합칠 때 사용했습니다.

#### 2. 브랜치 작업
프로젝트의 안정성을 위해 `main` 브랜치에서 직접 작업하지 않고, 기능별로 브랜치를 나누어 작업 후 병합(Merge)했습니다.

* **fix-favorite 브랜치**
  * **작업 내용**: 즐겨찾기 표시(별 모양)의 위치를 사용자 UI에 맞춰 보기 좋게 옮기는 작업을 진행했습니다.
  * **결과**: 작업 완료 후 `main` 브랜치에 병합하여 전체 시스템에 반영했습니다.

* **fix-view 브랜치**
  * **작업 내용**: "즐겨찾기만 보기" 기능에서 목록이 제대로 출력되지 않던 부분을 수정하고 기능을 생성했습니다.
  * **결과**: 테스트 완료 후 `main` 브랜치로 안전하게 병합했습니다.

* **main 브랜치**
  * **작업 내용**: 기본적인 CRUD(추가/조회/수정/삭제) 기능과 검색 기능을 구현했습니다.
  * **결과**: 최종적으로 완성된 상세 보기 및 인기 순위 기능을 통합하여 전체 프로젝트를 관리했습니다.

## ⭐ 보너스 기능 (선택 / 구현했다면)
### 1.수정/삭제(CRUD)
#### **CRUD란?**
   * **Create** add_prompt() 함수를 통해 새로운 프롬프트를 입력하고 저장
   * **READ** 전체 프롬프트 목록 보기, 특정 프롬프트 상세 보기, 검색하기
   * **Update** 프롬프트 내용을 수정하거나, 즐겨찾기(별표)를 껐다 켰다(Toggle) 하는 기능
   * **Delete** 더 이상 필요 없는 프롬프트를 삭제하는 기능
     
### 2.조회수·정렬 기능
   * **조회수 기능**
     * 키워드 필터링: if keyword in prompt['title'] or keyword in prompt['content']를 통해 제목, 내용까지 훑어서 검색 결과 생성
     * 조회수 증가 (views += 1): 사용자가 특정 번호를 선택해 상세 내용을 확인하는 순간, 해당 딕셔너리의 views 값을 1 증가 
   * **조회수 많은 순으로 정렬**
     * 데이터 정렬: key=lambda x: x['views']를 사용하여 딕셔너리의 views 값을 기준으로 정렬
     * 순위 매기기 (enumerate): enumerate(sorted_prompts, 1)을 사용해 별도의 변수 없이도 1번부터 순차적으로 번호를 매김
