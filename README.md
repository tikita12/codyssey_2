# 프로젝트 이름
> 나만의 프롬프트 관리

## 📌 프로그램 소개
> 여태까지 썼던 프롬프트를 한군데 모아 관리하기 쉽게 만드는 프로그램입니다.

## 🛠 개발 환경
- **Python 버전**: > 3.14.7
- **에디터**: > VSCode 사용, 설치한 확장(Python Extension, Korean Language Pack)
- **Git 버전**: > 여기에: 2.55.0.windows.5
- **운영체제**: > Windows

## ▶️ 실행 방법
> 1. git clone 명령어로 코드 복사 (https://github.com/tikita12/codyssey_2.git)
> 2. cd codyssey_2 명령어로 폴더 들어가기
> 3. python main.py를 입력하여 프로그램 실행하기

## ✨ 기능 목록
> 
- [1] 프롬프트 추가 → 새 프롬프트를 등록하는 기능
- [2] 프롬프트 목록 → 전체 프롬프트를 번호와 함께 보여주는 기능
- [3] 프롬프트 삭제 → 등록한 프롬프트를 삭제하는 기능
- [4] 프롬프트 수정 → 등록한 프롬프트를 수정하는 기능
- [5] 프롬프트 검색 → 키워드로 제목/내용을 검색하는 기능
- [6] 즐겨찾기 등록/해제 → 즐겨찾기 추가/해제 기능
- [7] 즐겨찾기만 보기 → 즐겨찾기한 것만 모아보는 기능 
- [8] 카테고리별 조회 → 카테고리를 골라 해당 프롬프트만 보는 기능
- [9]내용 상세 보기 → 번호 입력 시 전체 내용을 보여주는 기능 
- [10] 인기 순위 → 조회수가 많은순서대로 목록을 보여주는 기능
- [0] 종료 → 프로그램을 끄는 기능
